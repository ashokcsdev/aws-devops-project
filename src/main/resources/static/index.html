CI/CD Pipeline

Automated application delivery using Jenkins.

Jenkins Pipeline Stages

  • Checkout source code from GitHub
  • Build Spring Boot application with Maven
  • Terraform validation and plan
  • Build Docker container image
  • Push image to Docker Hub
  • Authenticate with Amazon ECR
  • Push image to Amazon ECR
  • Deploy application to Amazon EKS

Container Delivery

  • Spring Boot application packaged as JAR
  • Docker image created from the application JAR
  • Image published to Amazon ECR
  • EKS deployment references the ECR image
  • Deployment rollout is monitored by Jenkins
  • Kubernetes service exposes the application

Kubernetes Deployment

Application workload configuration running on Amazon EKS.

Application Deployment

  • Amazon EKS cluster
  • Two application replicas
  • Kubernetes Deployment resource
  • LoadBalancer Service
  • Port 80 to application port 8080

Health & Resources

  • HTTP readiness probe
  • HTTP liveness probe
  • CPU requests and limits
  • Memory requests and limits
  • Rolling deployment restart and status checks

Security

IAM and cloud security practices implemented across the project.

Identity & Access

  • GitHub Actions uses OIDC authentication
  • IAM roles are used for AWS access
  • EKS access is configured through AWS IAM
  • Jenkins uses an AWS IAM role

Infrastructure Security

  • Terraform manages infrastructure configuration
  • S3 Terraform state uses encryption
  • S3 state bucket versioning is enabled
  • Public access is blocked for Terraform state
